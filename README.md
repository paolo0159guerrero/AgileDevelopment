# Sistema de Control de Gastos — PMV

Sistema web desarrollado como Producto Mínimo Viable (PMV) para organizar los egresos, gastos variables y obligaciones de proveedores sin realizar transacciones bancarias automáticas.

## Funcionalidades Principales (Historias de Usuario)
- **HU-01 / HU-05:** Registro y corrección de obligaciones (Descripción, proveedor, categoría, monto y fecha de vencimiento).
- **HU-02 / HU-07:** Consulta mensual para el gerente con totales separados (Pendientes, Vencidos y Pagados).
- **HU-03:** Identificación y ordenamiento visual automático de los vencimientos más próximos.
- **HU-04:** Registro manual de pagos realizados por la asistente fuera del sistema.
- **HU-06:** Búsqueda rápida y filtros por estado.

## Tecnologías Utilizadas
- HTML5 y JavaScript (Vanilla)
- Tailwind CSS (vía CDN)
- LocalStorage para la persistencia local de datos en el PMV.
